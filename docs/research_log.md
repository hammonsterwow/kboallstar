# 연구 로그

## 2026-11-14 — GitHub 연구 아카이브 초기 구성

- 사용자가 작성한 KBO 올스타 연구계획서를 전사·문서화함.
- 「연구논문작성법」의 경험연구 절차에 맞춰 가설·종속변수·검증 방법 정리.
- 2009–2018 초기 선발 구단별 인원 **기존 예비 엑셀**을 텍스트 기반 CSV로 전사.
- 해당 데이터의 매년 참가 구단 수·선발 정원 합계만 기계적으로 점검. **원천 사실 검증과는 별도**.
- 투표 당시 구단 순위/승률을 통제변수 후보로 추가. 아직 값 미수집.
- 최우선 후속 작업은 2014–2018 **팬 단독 vs 실제 합산** 명단 재구성.
- 다음 단계에 필요한 CSV 스키마와 GitHub 이슈를 준비.

## 중요한 해석 결정

- 투표 결과와 팀 성적의 **동시성**을 피하려고 승률은 투표 마감 전 마지막 경기 기준으로 고정.
- 선발 0명 구단도 전체 모집단에 포함.
- 선발 정원·구단 수 달라진 시즌을 무시한 표준편차 단독 비교 금지.
- 팬 단독 가상 명단은 관측된 최종 팬 득표를 재사용한 **규칙 비교**이며, 제도 자체가 팬 투표 행태를 바꾸었을 가능성을 포함하지 않음.
- 원본 연구계획서의 '구단 대표성' 의미를 정책적 민주주의 대표성과 동일시하지 않고 사례 비유로 제한.
