# 2010 KBO 올스타 베스트10 후보별 최종 투표수 (80명)

2010년 팬 투표 100% 방식으로 진행된 동군/서군 **전체 후보 80명**의 최종 표를 전사했습니다.

- **원본:** 사용자가 제공한 [「2010 프로야구 올스타전 투표 최종 결과」](https://godlessjm.tistory.com/807)의 이미지 **두 장**. 게시: 2010-07-12.
- 투표 기간 종료: 2010-07-11. **중간집계가 아닌 최종 표**.
- 구성: 8구단, 동군 4/서군 4, 각 구단 10명 후보 → 리그별 40명, 전체 80명.
- 선발: 각 리그 투수 1, 포수 1, 1B/2B/3B/SS 1명씩, 외야수 3, DH 1 → 총 20명.
- 최다 득표: **홍성흔(롯데) 818,269표**, 2위 **류현진(한화) 779,938표**. 공식 당시 보도 설명과 이미지 숫자를 대조했습니다.
- **2010년 전체 유효투표수**는 두 원본 이미지에 표시되어 있지 않으므로, 확인 전까지 `ballots_total`에 숫자를 기입하지 않았습니다. 선수단 득표는 제도가 없어서 `N/A`입니다.
