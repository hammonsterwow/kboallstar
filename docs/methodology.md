# 경험연구 방법론 및 분석 설계

교수님의 「연구논문작성법」 자료에서 강조한 **연구 질문 → 가설 → 자료 수집 → 경험적 검증 → 결론 및 함의**를 따릅니다.

## 분석 단위와 처리 규칙

- **연도 단위**: 2009–2018년 각각의 전체 투표 최초 선발 명단 10개.
- **구단×연도 단위**: 각 시즌 참가 구단 0명 배출을 포함한 90개 행. 표본 독립성·연도 군집 문제를 고려해야 합니다.
- **포지션×리그×연도 단위**: 2014–2018년 팬 단독 1위와 합산 선발 1위의 차이를 직접 확인하는 핵심 분석 단위.
- 원본은 **팬/선수단 투표로 최초 확정된 베스트 선수**만 포함합니다. 감독 추천, 부상 대체 선수는 제거합니다.
- 2013년 NC·2015년 KT 참여 및 선발 정원 확대를 설명·조정합니다.

## 조작적 정의

1. **대표성의 폭**: `(1명 이상 배출한 구단 수)/(해당 연도 참가 구단 수)`.
2. **구단별 인원 표준편차 (모집단)**: 해당 연도 참가 **전 구단**의 투표선발 인원에 대한 `pstdev`.
3. **변동계수 (CV)**: `표준편차 / 전체 선발 인원 ÷ 참가 구단 수`; 분모를 명시하고, 연도 간 선발 정원 차이에 유의합니다.
4. **HHI**: 구단별 비중 `s_i = (구단별 선발 인원)/(해당 연도 총 투표선발 인원)`에 대해 `Σ(s_i²)`.
5. **제도 변경**: 2009–2013은 팬 투표 100%; 2014–2018은 팬 70%, 선수단 30% (동시기에 바뀐 세부 규칙을 확인).
6. **투표 마감 당시 구단 성적**: 투표 마감 전 마지막으로 완료된 경기의 `W/(W+L)` 기준 승률 및 당시 순위. 무승부 처리·공식 KBO 표시값 사용 여부를 통일합니다.
7. **팬 규모 대리변수**: 해당 시점까지 관중 누계 또는 시즌 관중 수. 어떤 기준을 사용했는지 필드에 명시합니다. 구단의 실제 투표 참여자 수와 동일하지 않습니다.

## 두 층위 분석

### A. 10개년 전후 비교 (기술통계)

- 연도별 대표성 비율, 표준편차, CV, HHI.
- 제도 전(2009–2013) 5개 연도 평균 vs 제도 후(2014–2018) 5개 연도 평균.
- 구단 수 8→9→10, 최초 선발 정원 20→22→24 변화 때문에 **단순 전후 차이로 원인을 확정할 수 없음**.
- 2013↔2014처럼 참가 구단 수·정원이 동일한 인접연도 비교도 보조적으로 실시.

### B. 2014–2018 같은 해의 팬 단독 vs 합산 결과 비교 (핵심)

1. 각 해 KBO 원자료에서 **최종 팬 득표 및 최종 합산 결과**를 확보.
2. **같은 해·리그·포지션별** 팬 득표 1위 선수를 찾아 팬 단독 가상 명단을 구성.
3. 실제 선수단 30% 포함 명단과 비교해 선발자 변경 여부 및 소속 구단 차이를 기록.
4. 두 명단에 대해 대표성 비율·모집단 표준편차·HHI를 비교.
5. **해석 제한:** 후보 선택·팬 참여에 제도 자체가 영향을 미칠 수 있으므로 '팬 투표 단독 가상 결과'는 엄밀한 정책 반사실이 아니라 **같은 관측 자료를 이용한 규칙 비교**임.

## 통제변수 및 위험요인

- **승률 / 순위**: 구단이 잘하는 시기에 인기나 선수 선발 가능성이 높아질 수 있으므로 투표 마감 시점으로 고정.
- **관중 수 / 구단 규모**: 팬 참여의 대리변수. 연고지 규모·구장 수용인원 등이 영향을 줄 수 있음.
- **연도/선발 정원 변화**: 참가 구단 수와 리그·포지션 구성이 달라 지표 해석이 변할 수 있음.
- **자기 구단 투표 제한** 등 규칙 변화: 선수단 30%의 전문가 가중 효과와 동시에 도입된 규칙을 분리해 해석할 것.
- **집계의 신뢰성**: 특히 2009, 2011, 2012, 2016 보도 기반 자료의 KBO 1차 자료 재대조 필요.
- **통계적 한계**: 단 5+5개 연도 비교, 구단×연도 자료의 독립성 위배 가능성, 인과효과 추정 한계.

## 검증 체크리스트

- [ ] 각 연도 실제 참가 구단 수와 팀명 확인
- [ ] 투표 마감일, 최종 선발 발표일 및 보도 출처 확인
- [ ] 구단별 인원 합계 = 해당 연도 선발 정원
- [ ] 0명 팀까지 포함해 지표 계산
- [ ] 포지션·리그별 후보명/구단명 검증
- [ ] 팬 단독/합산 비교에 결측·동률·선발 방식 예외 기록
- [ ] 구단별 승률·관중 누계 및 시점 기록
- [ ] 최종 논문 본문에 재현 가능한 그래프·표 제공
