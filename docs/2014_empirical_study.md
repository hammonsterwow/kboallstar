# 2014 KBO 올스타 선정: 팬 단독 vs 팬 70% + 선수단 30% 전수 분석

**연구 상태:** 후보 99명의 KBO 공식 최종 발표 득표표 전사 및 환산식·선발자 검산 완료(2026-11-14). 공식 웹페이지의 원표에서 전사했으므로 원본 문서를 다운로드하여 한 차례 더 육안 대조하면 보존·인용에 더욱 적합. **투표 종료 직전 팀 순위/승률은 아직 확정되지 않음.**

## 1. 출처와 방법

- KBO (2014-07-07), [「2014 올스타전 ‘베스트11’ 22명 확정」](https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=5556), 표1 2014 올스타전 베스트11 최종 집계.
- 팬 투표: 6월 10일~7월 4일 18시, 유효투표 1,782,008표.
- 선수단 투표: 291표, 자기 구단 후보에게 투표 금지 (KBO [3차 중간집계 공지](https://www.koreabaseball.com/MediaNews/Notice/View.aspx?bdSe=5542)).
- 참가 팀: 이스턴 E(삼성·두산·롯데·SK) 4팀, 웨스턴 W(LG·넥센·NC·KIA·한화) 5팀.
- 선발 대상: **각 리그 선발·구원·포수·1B·2B·3B·SS·지명타자 각 1명, 외야수 3명**, 리그당 11명, 총 22명. 감독 추천·부상 대체 제외.
- 후보 99명(웨스턴 55, 이스턴 44)의 리그/포지션/구단/팬 득표/선수단 득표/공식 점수를 전사.
- 공식 100점 환산 점수 검증: `70 * (후보 팬 득표 / 1,782,008) + 30 * (후보 선수단 득표 / 291)`. 공표된 소수 둘째자리 점수와 99명 전부에서 오차 0.011 이하.
- 팬 단독 가상 결과: 리그/포지션 내 팬 득표 1위, 외야수만 각 리그 상위 3명.
- 실제 합산 결과: 공식 환산 점수 1위, 외야수는 각 리그 상위 3명.

## 3. 포지션별 주요 사례

- **이스턴 포수:** 팬 투표 SK 이재원 676,247표 vs 두산 양의지 404,610표. 선수단 득표는 두산 양의지 103표, SK 이재원 100표로 역전. **그러나 최종 합산 점수는 이재원 36.87, 양의지 26.51**이므로 선발자는 동일.
- **웨스턴 외야수:** 한화 피에 팬 698,166표·선수단 71표·합산 34.74; LG 이병규(7) 팬 280,281표·선수단 76표·합산 18.84. 선수단 선호와 팬 선호 차이가 있었지만 최종 외야수 선발 3명은 팬 단독과 동일.
- **웨스턴 나성범:** 팬 968,013표, 선수단 193표, 합산 57.92점. 팬 득표 1위이며 공식 최고 총점을 기록.

**해석:** 특정 포지션에서 팬과 선수단의 선호 순위 차이가 있더라도, 선발 결과까지 변하지는 않을 수 있음. 2014년은 선수단 투표 반영 이후 *전 구단 대표성 100%*가 관측된 해이나, 동일한 팬 투표 데이터를 고정하고 선발 규칙만 바꿨을 때 대표성이 개선된 사례는 아님. 제도 도입 전 2013년과의 차이를 30% 가중치만의 영향으로 설명할 수 없음.
