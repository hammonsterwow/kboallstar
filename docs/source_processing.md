# 초기 데이터 처리 및 감사 기록

- 원자료 파일: 사용자가 기존 대화에서 전달받은 `KBO_올스타_구단별대표성_10개년_예비분석.xlsx`의 `구단별_원자료` 시트.
- 여기서 `data/raw/allstar_initial_selections_preliminary_2009_2018.csv`로 10개 연도, 팀별 원소, 구단 수, 선발 정원, URL, 메모를 전사.
- 원본 엑셀의 `분석요약`에는 **예비** 평균 대표성의 폭 71.1% vs 82.0%, 인원 모집단 표준편차 2.645 vs 2.099가 기록되어 있음.
- `yearly_metrics_preliminary.csv`는 입력 인원을 사용해 다시 계산한 값. **이는 수학적 재계산일 뿐 사료의 정확성 인증이 아님**.
- 원본 DOCX 및 연구방법 PDF의 바이너리는 저장하지 않고, 연구계획서 핵심 내용과 강의 지침만 Markdown에 정리. 원본이 필요한 경우 연구자가 개인 보관본/Drive 사본에서 확인해야 함.
- 근거 URL의 현재 접속 가능 여부 또는 본문 일치 여부를 이번 커밋에서 새로 검증하지 않았음.

**Audit after upload**
- 원문 기사에 나온 포지션별 선발자와 각 팀 인원이 일치하는지 재집계하기.
- 특히 KBO 공식이 아닌 2009/2011/2012/2016년 인용을 원문과 교차검증하기.
- 2013/2014 참가 구단 및 선발 정원 동일 조건을 활용한 보조 비교를 문서화하기.
