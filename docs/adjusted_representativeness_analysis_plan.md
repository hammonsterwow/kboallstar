# 승률·관중 규모를 고려한 구단별 대표성 보정 분석 설계

작성: 2026-11-24 · **분석 계획(제안), 결과 계산 전**.

## 1. 목적과 주 분석 구분

**핵심 연구 질문:** KBO 올스타에서 팬 투표 100%를 적용한 가상 베스트 명단과 팬 70%·선수단 30%의 실제 선발 명단을 비교했을 때, 구단별 대표성의 폭과 편중이 어떻게 달라지는가?

**주 분석은 보정하지 않은 실제 선발 결과의 비교**다.

- 매년 같은 후보·같은 팬 득표수 아래에서 '팬만으로 선발' vs '실제 팬+선수단 가중 선발'을 구성한다. 리그·포지션별 1위, 외야수는 3위를 반영.
- 구단별 선발 인원 0명을 포함해 배출 구단 비율(Breadth), 인원 표준편차, 변동계수(CV), HHI를 두 규칙별로 각각 계산한다.
- 이 동일 연도/동일 후보 비교는 그 시점의 구단 승률과 관중 규모가 두 시나리오에서 같으므로, **선발자 및 구단별 배분을 직접 비교할 때 승률·관중 '보정값'을 투표수에 곱할 필요가 없다**.
- 단, 투표제도 시행 자체가 팬 행동이나 후보 구성을 바꿨을 수 있으므로 이 비교는 관측 자료에 대한 **규칙 시뮬레이션**이지 엄밀한 정책 인과효과 추정이 아니다.

## 2. 보조 분석의 역할: '정상적인 선발자 수'가 아닌 '설명변수 기반 예측값'

승률과 관중 수는 각 구단의 팬 투표 선발 인원을 예측하는 데 사용할 수 있는 **설명변수**다. 이를 이용하여 선수단 가중치로 인한 선발자 변화가 당시 경기력·관중 규모와 어떤 관련이 있었는지 조사한다.

**관찰 단위**: 연도(t)×올스타 리그(ℓ)×구단(i). 포지션 규칙 시뮬레이션은 별도 원자료를 유지한다.

### 수집할 입력

1. **투표 마감 직전 승률** `W/(W+L)` — 경기일·승·패·무·승률·리그 순위·게임차·근거 URL. 시즌 종료 승률 사용 금지.
2. **투표 마감 직전 누적 홈 관중 및 홈 경기 수** — 합산 기준일, 경기당 평균 관중, 데이터 URL. 규모 차이와 경기 배정을 감안해 경기당 평균 관중을 주 지표로 제안.
3. 연도·리그·참가 구단 수·그룹 선발 정원. 구단명 변경은 동일 프랜차이즈 ID로 연결. 0명 선발은 0, 아직 참가하지 않은 구단은 결측.
4. 2020·2021년은 코로나19 관중 제한으로 별도 구분하고, 팬 100% 특별 시행 시기이므로 70:30 직접 비교에서는 제외.

**이미 확보한** [연간 홈 관중 170개 구단-연도 CSV](../data/raw/attendance_by_team_full_season_2009_2026.csv)는 **시즌 종료 시점** 자료이다. 투표 마감 직전의 관중 규모를 대체하여 주 회귀에 사용해서는 안 된다. [투표 마감일 누적 관중 수 입력 템플릿](../data/templates/attendance_at_vote_close_2009_2026.csv)은 아직 값이 채워지지 않았다.

### 변수 변환(수집 후)

연도·올스타 리그 안에서 상대적 성적·관중 규모를 표준화하는 방식을 제안한다.

```text
win_pct[i,t] = wins[i,t] / (wins[i,t] + losses[i,t])
crowd_avg[i,t] = cumulative_home_crowd / number_of_home_games
crowd_log[i,t] = ln(1 + crowd_avg[i,t])

z_win[i,t]   = (win_pct[i,t]   - league_year_mean(win_pct))   / league_year_sd(win_pct)
z_crowd[i,t] = (crowd_log[i,t] - league_year_mean(crowd_log)) / league_year_sd(crowd_log)
```

그룹 내 표준편차가 0이거나 기록이 결측인 경우 표준화값을 무리하게 계산하지 말고 결측으로 표시·원인 점검한다. 순위는 동일한 정보를 중복 제공할 수 있으므로 기본 모형에는 승률만 포함하고, 순위 또는 1위와의 게임차를 대체·강건성 분석에 사용한다.

## 3. 선택 가능한 탐색적 예측 모형

그룹 전체 선발 정원 `S[ℓ,t]`을 유지하도록 상대적 가중치를 정한다.

```text
weight[i,t] = exp(beta_win * z_win[i,t] + beta_crowd * z_crowd[i,t])
predicted_seats[i,t] = S[ℓ,t] * weight[i,t] / sum(weight[j,t] for j in same ℓ,t)
```

- `beta_win`, `beta_crowd`는 **0.5 같은 임의의 상수로 정하지 않고**, 팬 단독 선발 구단별 인원 자료를 이용한 연도·리그 조건부 카운트/다항 모형 등으로 **통계적으로 추정**한다.
- 예상 선발 인원은 소수가 될 수 있다. 이는 법적·도덕적으로 '당연히 받아야 할 선발권'이 아니라, **승률·관중 자료로 설명되는 기대 선발 인원**이다.
- 독립적 포지션 선발 한도, 후보 개인의 실력과 인기, 원정 팬, 지역·구장 규모는 이 단순 모형에 충분히 반영되지 않는다.
- 팬 단독 결과로 계수를 학습하면 예측값이 팬 단독 결과에 구조적으로 더 잘 맞는 **학습 기준 편향**이 생길 수 있다. 따라서 잔차가 작다는 사실을 곧 '더 공정하다' 또는 '대표성이 더 높다'고 해석해서는 안 된다. 가능하면 연도를 나눠 교차 검증하며 학습·평가를 분리한다.

### 잔차와 비교

```text
residual_fan[i,t]      = fan_only_seats[i,t] - predicted_seats[i,t]
residual_weighted[i,t] = weighted_seats[i,t] - predicted_seats[i,t]
delta_seats[i,t]       = weighted_seats[i,t] - fan_only_seats[i,t]
```

- **핵심 보조 결과:** `delta_seats`가 어떤 구단(낮은 팬 규모, 낮은 승률, 기존 대표 구단 0명)에 집중되는지 구단별 사례와 분포를 탐색한다.
- `residual`은 통계적 **설명 부족분**이며, 선정의 정당성·공정성 또는 실제 선수 실력을 판정하지 않는다.
- '보정 대표성 지수'를 임의로 새로 정의하여 원래 대표성 지표를 대체하지 않는다. 기본 지표는 늘 원값으로 먼저 보고한다.
- 연도별 70:30 vs 팬 단독 차이는 `ΔBreadth=B_weighted−B_fan`, `ΔHHI=HHI_weighted−HHI_fan`로 산출하며, 후보 선발 변경 횟수·구단별 증가/감소를 함께 보고한다.

## 4. 시기 구분과 특수 상황

- **2009–2013:** 팬 100% 제도, 제도 도입 전 기술통계 비교.
- **2014–2019, 2022–2026:** 팬 70%+선수단 30% 제도, **해당 연도 팬 100% 가상 vs 실제 70:30의 짝비교가 가능한 11개 연도**. 2014년 9구단 체제, 그 이후 10구단 체제.
- **2020–2021:** 팬 100% 특별 시행, **팬 단독 제도 관찰값만 기록**. 원자료 120명씩 전수 확보됨. 코로나19로 관중 수의 팬 규모 대리변수 성격도 왜곡되므로 보조적 기술통계 및 별도 민감도 분석.
- 2021 나눔 1루수 **라모스(LG)의 원래 팬 1위 → 웨이버 공시로 박병호(키움) 공식 대체 선정**. `fan_only_selected`와 `official_selected`를 구별하고, 선수단 투표 효과로 계산하지 않는다.
- 2013 NC·2015 KT 참가로 리그 구단 수와 선발 정원이 바뀌었다. 비교 시 참가 구단 수와 각 리그 선발 정원을 반영한다.
- 각 팀의 구단-연도 관찰치는 독립 표본이 아니고 같은 연도·리그 그룹 내 선발 정원이 고정돼 있다. 단순 독립 관측 회귀 및 과도한 인과 결론에 주의한다.

## 5. 향후 분석·보고 순서

1. 각 연도 투표 마감일, 마감 직전 공식 승률·순위·승패무, 누적 홈 관중·홈 경기 수·평균을 수집하고 **원본 URL·날짜를 남긴다**.
2. 2009–2026 후보별 원자료와 구단-연도 관중/성적 자료를 조인하고, 참가구단·투표 마감 기준일·예외 선수를 대조한다.
3. **주 분석:** 팬 단독 vs 실제 70:30의 선발 변경 및 대표성·HHI·표준편차를 연도별로 보고(해당 11개년).
4. **보조 분석:** 승률·관중 규모와 팬 단독 선발 인원 간 관계를 추정하고, 선수단 반영으로 얻거나 잃은 선발 인원(`delta_seats`)과 설명변수의 관련성을 살핀다. 선택적으로 예측값과 잔차를 비교하되 예측 모형의 성능·학습 편향도 함께 보고한다.
5. **강건성 분석:** 승률↔순위 대체, 관중 로그·경기당 평균 측정 대체, 2020–2021 제외, 구단 수·리그 정원 통제, 필요시 비모수 연도별 차이 검정. 임의 계수·근거 없는 p값·인과효과 수치를 만들지 않는다.
6. 결과를 원자료/표/계산 스크립트와 함께 재현 가능하게 저장한다.
