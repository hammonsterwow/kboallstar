## 3. 검증

- 이미지의 10행 × 8개 구단 = **80개의 후보별 정확한 득표수**를 CSV 전사함.
- 각 리그의 각 포지션별 팬 득표 최대 1명씩, 외야수 3명씩을 계산함. 선발 cutoff 동률 없음.
- Eastern: **롯데 10명**, SK 0, 삼성 0, 두산 0.
- Western: **KIA 3, LG 3, 한화 2, 넥센 2명**.
- 합계 = **20명**, 기존 2012년 구단별 예비 집계와 일치.
- 참고: 단일 후보의 득표수와 전체 유효투표수는 다른 값이며, 80명 득표를 모두 합산해서 투표 참여 수로 간주하지 않음.
