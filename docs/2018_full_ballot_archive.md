## 대상과 검증

- 전체 후보 120명(드림60, 나눔60); 최종 선발 24명, 감독 추천/부상 대체 제외.
- 팬 투표 **841,693표**, 선수단 투표 **352표**, 70:30 반영.
- 전체 120명 팬 득표·선수단 득표·공식 점수 입력 후 `70 * fan_votes / 841693 + 30 * players_votes / 352`로 검산. 모두 **0.005점 이내 오차**.
- 포지션별 팬 득표 상위 1명(외야수 3명)과 공식 합산 점수 상위 1명(외야수 3명)을 비교.
- **선발이 다른 자리는 6/24명이며 모두 나눔 올스타**.
